FileResponsibility

Dashboard (web/ui/)

FileResponsibility

sessions.jsHistory sessions, timeline, laps, GPX/CSV export
info.jsGlossary UI (search, chips, expand)
info-data.jsGlossary content (69 terms, 8 groups)
mqtt-mini.jsLightweight MQTT over WS client
guard.jsOperator lock (long-press)

API tester (web/api/docs/)

FileResponsibility
index.htmlStatic tester page, one card per endpoint
app.jsRequest builder, fetch, status/timing/headers/body panel, curl preview

The tester is static and outside web/doc/: it calls the base URL directly, never proxies, and never embeds the ingest key. Verify key posts an empty body so the auth check runs without writing a row.

Data Flow


ESP32 (1 Hz)
    │
    ├─ MQTT → HiveMQ (wss) ──→ Dashboard (live tabs)
    │
    └─ HTTPS batch (30s) ──→ Cloudflare Pages Function ──→ D1
                                                      │
                                                      └─ GET /history ──→ Dashboard (HIST tab)

Key Invariants (enforced by tests)

  • All assets share same ?v= (ui.test.js)
  • No camera/pitch/rotate buttons on map (ui.test.js)
  • Phone basemap keeps all text labels (ui.test.js)
  • Accuracy circle uploaded once per fix (ui.test.js)
  • MPU3D math pure functions, testable under node (mpu3d.test.js)
  • Dashboard calls MPU3D.draw() on tab open + resize (ui.test.js)
