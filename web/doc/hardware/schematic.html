Power Considerations

ComponentVoltageCurrent (typical)
ESP323.3V80–240 mA (WiFi active)
NEO-6M3.3V30–50 mA (acquisition)
MPU60503.3V3–5 mA
Total3.3V~150–300 mA
  • ESP32 DevKit onboard LDO (AMS1117) handles up to 800 mA → sufficient
  • Add 100 µF + 100 nF decoupling near ESP32 3V3/GND if using long wires
  • NEO-6M cold start draws more current → ensure stable 3.3V

Antenna Placement

SensorRequirement
NEO-6MCeramic patch antenna needs clear sky view. Keep >5 cm from ESP32 WiFi antenna, metal, carbon fiber. Horizontal mount (patch facing up).
MPU6050Mount flat on vehicle chassis. Align axes: X = right, Y = forward, Z = up. Secure rigidly (double-sided tape + zip tie).
