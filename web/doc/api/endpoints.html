API Endpoints Reference

Base URL: https://race-tracker-history.pages.dev (Cloudflare Pages Function).

Public read. Writes require X-Ingest-Key. All responses are JSON.

Try it live: API Tester — send every endpoint from your browser, with the response status, timing, headers and body on screen. Reads need nothing; the ingest key is typed at runtime and never embedded in the page.
MethodPathAuthPurpose
GET/health—Liveness
GET/history—Stored fixes + laps
GET/live—Newest sensor frame, right now
POST/ingestX-Ingest-KeyDevice batch upload
OPTIONSany—CORS preflight, 204

Unknown paths on the Pages deployment fall through to the static landing page (200, HTML), because Pages treats a missing 404.html as a single-page app. The JSON error shape applies to the Worker entry and to a known path called with the wrong method: 404 { "ok": false, "error": "not-found" }.

Full request/response detail lives in history.md and live.md; the telemetry payload itself is documented in mqtt.md.

GET /live

Newest frame the device published, read from the broker's retained message — the same data as the live dashboard. No database read or write.
