Orion API Tester

Send real requests to the history API from this page. Each request goes straight from your browser to the base URL below — no proxy, no server, no logging. Schemas live in the endpoint reference and the history API; the live telemetry stream is on the dashboard.

Writes are real. POST /ingest with a valid key inserts rows into D1. Use Verify key first — it proves the key is accepted without storing anything. The ingest key is never embedded in this page and never sent anywhere except the base URL.

Cloudflare Pages Function

Default: the public history API. For a local run use http://localhost:8788.

          GET
          /live
          no auth · read
        

        
Everything the sensors are reporting right now: the newest frame the device published, read from the broker's retained message. Same fields as the live payload — GPS fix, speed, satellites, roll/pitch/yaw, tilt, MPU temperature and chip temperature. Nothing is written to the database.

A GET on the write-only /ingest route is not handled, so it returns 404 {"ok":false,"error":"not-found"}. That proves the JSON error shape without touching data. (Arbitrary paths on the Pages deployment fall through to the static landing page instead.)
